Privacy Policy

1. Overview of Data Practices

Cerolingo is committed to maintaining absolute user privacy. The extension functions strictly as a client-side automation utility. It does not harvest, intercept, track, or extract any user personal data, account credentials, browsing histories, or network metrics for remote collection.

2. Local Storage & Scope of Execution

The extension requests browser profile storage privileges (chrome.storage.sync) solely to preserve configuration states locally (such as automated navigation parameters and temporary session IDs). All calculations, DOM reading, and session parameters run fully isolated within your web browser's environment.

3. Third-Party Interactions

Cerolingo communicates directly and exclusively with Duolingo infrastructure endpoints to facilitate automated lesson resolution. It features zero integration with third-party analytical dashboards, tracking networks, advertising tools, or external telemetry cloud servers.

4. Core Compliance Declarations

Pursuant to global developer guidelines and web store transparency standards, we explicitly confirm:

  • No Data Exploitation: User information or structural data is never sold, traded, rented, or transferred to third-party entities under any circumstances.
  • Strict Contextual Use: No permissions or processed parameters are utilized outside the extension's explicit functional scope.
  • No Credit or Analytical Tracking: Collected automation loops are never deployed to evaluate financial status, profile behavior, or establish user creditworthiness.

5. Changes to This Policy

As Cerolingo functions strictly local to your machine, updates to this privacy policy will coincide with public extension version releases. Continued use of the extension following an update constitutes acceptance of any minor maintenance adjustments to these terms.
